# CALL-CENTER-DATA-ANALYSIS

 Project Overview
This project analyzes call center data using Excel to understand customer interactions, agent performance, and overall service efficiency.

 Objectives
- Analyze call volumes and trends
- Evaluate agent performance
- Measure customer satisfaction
- Identify areas for improvement

Key Metrics
- Total Calls
- Resolved Calls
- Unresolved Calls
- Average Call Duration
- Customer Satisfaction Score
- Agent Performance

Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Excel Functions Features
- Call volume analysis
- Agent performance tracking
- Customer satisfaction insights
- Resolution status monitoring
- Data visualization using charts and pivot tables


 Dataset
The dataset contains call center records such as:
- Call ID
- Agent Name
- Call Duration
- Call Status
- Customer Satisfaction Rating

 Purpose
 
The goal of this project is to identify trends, measure performance, and improve customer service efficiency.

 Conculsion
 
 The Call Center Dashboard provides a comprehensive view of call center operations and performance.
